使用手册
快速开始
  1. 首次打开输入默认密码 admin 登录
  2. 登录后点击「新建日记」开始记录
  3. 填写标题，在模板板块中记录今天的经历、心情、灵感等
  4. 点击「保存日记」完成记录
  5. 建议首次登录后在设置中修改密码
写日记
  1. 在输入框中自由书写，记录今天发生的事、心情、灵感等
  2. 选择表情标记今天的心情
  3. 点击麦克风按钮可以语音输入，自动转为文字
  4. 添加标签方便分类和搜索
  5. 写完后点击「保存日记」完成记录
AI 分析
  1. 先在「AI 设置」中配置 DeepSeek API Key
  2. 也可以开启「免费模式」，无需 API Key
  3. 写完日记后点击「AI 分析」按钮
  4. AI 会分析你的情绪、主题，给出反思和建议
  5. 分析结果自动保存，重新分析会覆盖旧结果
  6. 支持三种风格：温暖陪伴、理性分析、赛博朋克
综合分析
  1. 点击侧边栏「综合分析」查看数据概览
  2. 支持按时间范围筛选：本周/本月/本年/全部/自定义
  3. 心情时间线直观展示情绪变化趋势
  4. 点击「AI 综合分析」获取深度总结报告
搜索、管理与批量操作
  1. 「所有日记」页面可按心情筛选、按时间排序
  2. 开启「批量选择」可以全选、批量删除、批量导出
  3. 鼠标悬停日记卡片右下角，出现删除和导出按钮
  4. 「搜索」支持标题、内容、标签全文搜索
  5. 点击日记卡片可以编辑已有日记
导入导出
  1. 导出 JSON — 完整备份所有日记（含 AI 分析）
  2. 导出 Markdown — 纯文本格式，方便阅读
  3. 导出完整报告 — HTML 文件，包含统计和 AI 分析
  4. 导入 JSON — 从备份恢复数据
  5. 建议定期导出备份，防止数据丢失
移动端使用
  1. 在手机浏览器中打开即可使用
  2. 底部有快捷导航栏（新建/日记/搜索/分析）
  3. 点击麦克风按钮开始语音输入，自动将语音转为文字
  4. 再次点击麦克风按钮停止录音
  5. 建议「添加到主屏幕」获得更好的使用体验
隐私与安全
  1. 所有数据存储在你的浏览器本地，不会上传到任何服务器
  2. API 密钥仅保存在本地浏览器中
  3. 建议定期修改登录密码保护隐私
  4. 将文件夹发给他人时，对方获得的是全新空数据库
